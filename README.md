#### Description

This project demonstrates API Integration and Data Visualization using Python. The application fetches real-time weather data from the OpenWeatherMap API for multiple cities and analyzes important weather parameters such as temperature and humidity. The collected data is processed using the Pandas library and visualized through graphs using Matplotlib and Seaborn.

The project creates a simple dashboard that displays:

* Temperature comparison of different cities using a bar chart.
* Humidity analysis using a line chart.

This task helps in understanding:

* Working with public APIs
* Fetching JSON data
* Data processing using Pandas
* Creating visualizations and dashboards in Python

The generated dashboard is also saved as an image file for reporting and presentation purposes.
